# Matter Lab

Локальная студия для построения физических сцен, съёмки и монтажа вертикальных видео. Продюсер собирает сцену из предметов, задаёт движение и связи, снимает опыт вручную или автокамерой, добавляет собственные титры и экспортирует MP4. Генеративное видео и облачные сервисы не нужны.

## Запуск из исходников

Нужен **Node.js 24**; поддерживается версия от 22.12. Установите зависимости по зафиксированному lockfile:

```sh
npm ci
npm run dev
```

Откройте <http://127.0.0.1:4310/>. На macOS можно использовать `Запустить Matter Lab.command`. Для редактора и расчёта репетиций достаточно Node.js. Для финального рендера дополнительно нужны **macOS, Swift Command Line Tools, Metal и FFmpeg** в PATH. В Linux работает редактор, расчёт и звуковая репетиция; экспорт MP4 требует подключённого Mac render worker.

Для запуска собранной версии:

```sh
npm run build
npm start
```

Параметры окружения описаны в `.env.example`. Например, собственный каталог проектов и порт:

```sh
MATTER_LAB_DATA_DIR=./data MATTER_LAB_PORT=4312 npm start
```

При заданном `MATTER_LAB_DATA_DIR` проекты, видео и кэш хранятся в его подпапках. Без этой переменной видео пишутся в `../matter-lab-videos`, проекты — в `.cache/projects`. Сохранение JSON позволяет переносить сцену между установками. Браузерное автосохранение привязано к адресу студии.

## Рабочий процесс

1. Выберите подготовленную сцену или свободную студию. В каталоге **308 предметов**: бытовые вещи, мебель, еда, инструменты и составные модели.
2. Разместите предметы вручную или конструктором: решётка XYZ, линия, кольцо, спираль, ступени, заполнение области. Построение сохраняет шаблон и может быть перестроено с другими параметрами. Можно повторять группу связанных предметов.
3. Настройте материал, массу, затухание линейного и вращательного движения, масштаб добавленного объекта, положение, поворот, трение, отскок, линейную и угловую скорость. Добавьте отложенные запуски, источники предметов, опоры, шарниры, пружины, невесомые верёвки и жёсткие соединения. У верёвки задаются два локальных крепления и **максимальная длина**: она ограничивает растяжение и не толкает предметы при сближении. У пружины отдельно задаются длина покоя, жёсткость и затухание.
   В разделе **«Внешний вид»** можно задать единый цвет, шероховатость и металличность обычного твёрдого или мягкого предмета. Эти настройки не меняют физику; сброс возвращает исходную окраску частей. Внешний вид сохраняется при копировании, сохранении проекта и экспорте.
   Редактор **«Модели взаимодействия»** позволяет включить деформацию поддерживаемой оболочки, настроить осевое проникновение выбранной пары, собрать разрываемые связи либо задать однородную атмосферу и вытесненный объём твёрдого предмета. Модели включаются явно и имеют отдельные параметры; один выбор материала не включает все возможные явления.
4. Снимите опыт: статичный ракурс, запись управляемой камеры, ключевые кадры либо автоматическое кадрирование. Экранное время независимо от физического: можно замедлить, остановить или повторить момент, продолжая движение камеры. Цель взгляда задаётся для каждого ключа: предмет, группа, смещение и характер перехода; опора перемещения камеры задаётся отдельно.
5. Добавьте **свой текст**. Временная дорожка задаёт интервалы титров; пустые участки остаются без текста. Доступны оформления «Студия», «Плакат» и «Наблюдение», положение, размер, выравнивание, светлый или тёмный текст и подложка. Числовые подстановки, например `{physicalSeconds}`, `{temperature}` и `{depthCm}`, показывают наблюдения текущей модели, если она их предоставляет. Физическое время при замедлении отличается от времени ролика. Пространственные подписи можно закрепить в мире или привязать к предмету: это удобно для шкал высоты и пояснения устройства. Подписи и оформление не меняют результат симуляции; выводы за автора программа не сочиняет.
6. Соберите до **48 независимых клипов / 180 секунд**. У каждого свои предметы, настройки, камера и текст. Доступны перестановка, копирование, длительность, диапазон опыта, обрезка и разделение маршрутов записанной камеры и ключей.
7. Проверьте монтаж в репетиции с перемоткой и звуком. Звук включается отдельной кнопкой. Финальный свет и сглаживание отличаются от интерактивного просмотра.
8. Выберите дорожку из 36 локальных инструментальных композиций (включая четыре записи Loyalty Freak Music под CC0) и настройте звук. Экспорт: **720×1280, 1080×1920, 2160×3840; 24/30/60 кадров/с; H.264 + AAC**. Для 4K создаётся также Full HD копия.

Экспорты ставятся в очередь: один активный и до восьми ожидающих. Для каждого задания сохраняется независимый снимок проекта. После перезапуска ожидающие задания продолжаются, прерванный рендер отмечается отдельно. Видеостудия показывает очередь и готовые ролики в вертикальных карточках: можно посмотреть видео, скачать файл и открыть сохранённый проект для правки. Просмотр по ссылке `/watch.html?v=<имя>.mp4` запускается без звука; зритель включает его самостоятельно. Отсутствующий локальный экспорт не входит в исходную поставку автоматически.

В библиотеке шаблонов доступны четыре полностью редактируемых проекта: нагретый стальной цилиндр и лёд, свод с извлекаемым замком, прибор с 90 жемчужинами и волна маятников. Это обычные данные сцены и монтажа; код решателя не содержит веток, подменяющих их исходы.

Сравнение параметров применяет разные значения скорости, массы, материала, гравитации или угла к одной и той же исходной сцене. Примеры проектов используют общие инструменты и не подменяют физические результаты.

## Физические модели и границы

| Подсистема | Реализовано | Границы |
| --- | --- | --- |
| Твёрдые тела | Rapier: составные коллайдеры, масса, инерция, контакт, трение, отскок, соединения, гравитация | Каталожные машины и приборы — пассивные модели, без двигателя или электрических функций |
| Деформируемые объёмы | FEM Rapier: тетраэдральная сетка, упругость, затухание, остаточная деформация; банан, шар, эллипсоид и авторская замкнутая треугольная оболочка | Составные пересекающиеся детали не объединяются автоматически в мягкое тело. Сетка ограничена по размеру, пресеты не откалиброваны по реальным образцам |
| Разрываемые сборки | Жёсткие тела соединены физическими связями; при превышении заданного порога связь удаляется и тела продолжают движение в Rapier | Нагрузка оценивается по графу контактов (`contact-graph`), а не по точной силе в каждом соединении. Нет расчёта трещин, напряжений материала или дробления произвольной геометрии |
| Атмосфера и подъёмная сила | Для явно заданного вытесненного объёма: сила Архимеда `F = −ρVg`, приложение в локальном центре объёма и квадратичное сопротивление относительно ветра | Однородный газ постоянной плотности, жёсткий постоянный объём и заданные коэффициенты. Нет погружения в жидкость, расширения оболочки, утечек, турбулентности или аэродинамической подъёмной силы крыла |
| Центральное тяготение | Закон обратных квадратов, velocity Verlet, регулируемые масса и радиус тела | Вакуум, отдельная модель; размер запускаемого предмета визуально увеличен |
| Тепловое проникновение | Баланс энергии горячего шара и энтальпия плавления льда | Оценочный теплообмен, без паровой плёнки, теплового поля и механического разрушения |
| Осевое проникновение и контактное плавление | Отдельная одномерная модель цилиндрического снаряда: эффективное сопротивление, конечный запас тепла и плавление канала. Пара снаряд–образец, ось и параметры выбираются в проекте | Не откалибрована по экспериментальным ударам. Разрез канала — приближение эквивалентного объёма, а не решение трёхмерной теплопроводности, течения воды, паровой плёнки или разрушения |
| Частицы жидкости | Double Density Relaxation, вязкость, подготовленный желоб и резервуар | Нет общей двусторонней связи с произвольными телами, жидкостной плавучести или химических реакций. Газовая модель выше не добавляет эти возможности жидкости |

Свободная сцена рассчитывает общую механику. Специализированные тепловые, жидкостные и деформируемые модели имеют свои области применения; приложение не является универсальным научным решателем. Число доступных предметов не означает, что любая пара материалов умеет гореть, плавиться или разрушаться.

В атмосферной модели автор задаёт плотность газа, вытесненный объём, его центр, коэффициент сопротивления и опорную площадь. Масса предмета должна включать всё его содержимое и оболочку: указание объёма само по себе не превращает предмет в гелиевый шар. Объём и площадь задаются в физических единицах после масштабирования; при масштабировании связанной группы конструктором они пересчитываются вместе с креплениями. Цвет и внешний вид этих физических данных не заменяют.

Лимит свободной сцены — **150 добавленных предметов**; подготовленная сцена может содержать дополнительные тела. Расчёт механики использует шаг 120 Гц, экспорт интерполирует положения и повороты. У твёрдых тел детализированная визуальная геометрия отделена от коллизий, поэтому изменения только оформления не должны менять исход опыта. Оболочка FEM, напротив, участвует в построении физической сетки.

Проверка численной сходимости и баланса энергии проверяет расчёт в рамках принятых допущений. Для количественного предсказания реального опыта нужны измеренные свойства и проверка применимости модели. Художественный результат также требует отдельного просмотра: расчёт сам по себе не гарантирует понятную камеру, выразительный монтаж или фотореалистичное изображение.

Счётчик сдвинутых предметов отмечает тела, которые хотя бы раз удалились от начала на заданный порог (по умолчанию 20 см). Это не число предметов, оставшихся сдвинутыми в последнем кадре.

## Проверки и структура

```sh
npm test
npm run build
```

Общий набор проверяет модели, библиотеку, свойства предметов, связи, сохранение, камеру, монтаж, титры и звук без GPU/FFmpeg. Проверки интерфейса и художественного результата выполняются отдельно. CI для Linux и проверки компиляции Swift настроен в `.github/workflows/ci.yml`; наличие конфигурации не означает, что удалённый CI уже запускался.

Сайт в контейнере и native renderer разделены. Готовый локальный релиз — неизменяемый снимок, пользовательские данные хранятся отдельно. Это пока инструмент рабочей станции: облачные аккаунты, совместное редактирование и публичный многопользовательский сервис не реализованы.

## Чистая поставка исходников

```sh
npm run package:source
```

Создаёт `release/Matter-Lab-<version>-source.tar.gz` и SHA256. Состав задаётся явным списком: исходники, общедоступные ресурсы, lockfile, документация и конфигурация. Пользовательские проекты, `.env`, кэш, видео, `node_modules`, `dist` и Mac runtime не включаются. Перед передачей новой версии выполните проверки выше и проверьте распакованный архив.

Лицензия собственного кода владельцем пока не выбрана. Этот комплект не назначает open-source лицензию и ничего не публикует. Публичное распространение готового FFmpeg runtime проверяется отдельно от исходников приложения.
